@appendix{app-examples} Index of the Example Programs
@index examples directory
The directory `examples/` of the source tree contains one small program for each feature of the language. The table lists them with the command used to build them, the expected result, and the section of this manual that explains the feature. (The comments inside those files are written in Spanish; the explanations in this manual are the English reference.)
