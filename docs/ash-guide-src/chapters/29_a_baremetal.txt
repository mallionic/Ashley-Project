@chapter{ch-baremetal} Bare-Metal Programming: The VGA Text Screen
@index bare metal; VGA; 0xB8000
A program that runs *on bare metal* runs directly on the processor, with no operating system underneath: it is the first code of a kernel, a boot loader, a firmware or an embedded system. There is no `printf`, no files and no C library. To show something on the screen the program writes directly into the memory of the video card. This chapter explains how a PC screen works in text mode, builds a minimal kernel in ASH that writes to the screen at address `0xB8000`, and grows it into a small VGA driver. Every screen shown here is a real screenshot of the program running in the QEMU emulator.

@section{bm-memory} The Memory of a PC
When a PC starts, the first megabyte of the address space has a fixed layout inherited from the original IBM PC. Some of these regions are not ordinary memory but windows into hardware:

@table widths=24,24,52 title="The first megabyte of a PC" label=tab-pc-memory
Address | Size | Content
`0x00000` | 1 KiB | Interrupt vector table (real mode).
`0x00400` | 256 bytes | BIOS data area (keyboard buffer, timer ticks, screen size...).
`0x07C00` | 512 bytes | Where the BIOS loads a boot sector.
`0xA0000` | 64 KiB | VGA graphics memory (mode 13h: 320 x 200 pixels, one byte each).
`0xB8000` | 32 KiB | VGA **text** memory: the characters you see on the screen.
`0xF0000` | 64 KiB | The BIOS itself.
`0x100000` | ... | Extended memory, above 1 MiB: where kernels are usually loaded.
@end

@section{bm-text} How the Text Screen Works
@index text mode; attribute byte
In text mode the screen has 80 columns and 25 rows. Each position, a *cell*, is stored as **two bytes** at address `0xB8000 + (row * 80 + column) * 2`:

@table widths=20,80 title="One cell of the text screen" label=tab-vga-cell
Byte | Meaning
first | The character code, in code page 437: the ASCII characters plus line-drawing and block characters such as `0xDB` (a full block) and `0xC9` (a double-line corner).
second | The *attribute*: the foreground color in bits 0–3 and the background color in bits 4–6. Bit 7 makes the character blink (or selects a bright background).
@end

Writing two bytes at the right address makes a character appear immediately: the video card reads this memory about seventy times per second.

@table widths=10,22,10,22,10,26 title="The 16 text colors" label=tab-vga-colors
Value | Color | Value | Color | Value | Color
0 | black | 6 | brown | 12 | light red
1 | blue | 7 | light gray | 13 | light magenta
2 | green | 8 | dark gray | 14 | yellow
3 | cyan | 9 | light blue | 15 | white
4 | red | 10 | light green | |
5 | magenta | 11 | light cyan | |
@end

An attribute is computed as `background * 16 + foreground`: `0x1F` is white (15) on blue (1), `0x4E` is yellow on red, `0x07` is the usual light gray on black.

@section{bm-skeleton} The Skeleton of a Kernel
The kernels of this chapter are started by QEMU's built-in *multiboot* loader (`qemu-system-i386 -kernel kernel.elf`), which loads them at 1 MiB in 32-bit protected mode. Two small files are shared by all of them; [[ch-multiboot]] explains them line by line.

@code asm file=boot.asm title="boot.asm: the entry point, written for shasm"
; boot.asm - multiboot header, stack and entry point of an ASH kernel
bits 32

MB_MAGIC equ 0x1BADB002
MB_FLAGS equ 0                    ; no special requests to the boot loader

section .multiboot
align 4
    dd MB_MAGIC
    dd MB_FLAGS
    dd -(MB_MAGIC + MB_FLAGS)     ; checksum: the three fields add up to 0

section .bss
align 16
stack_bottom:
    resb 16384                    ; 16 KiB of stack
stack_top:

section .text
global _start
extern kmain
_start:
    mov esp, stack_top            ; the loader does not give us a stack
    push ebx                      ; second argument: multiboot information
    push eax                      ; first argument: magic number 0x2BADB002
    call kmain                    ; kmain(magic, info), written in ASH
.hang:
    cli
    hlt
    jmp .hang
@end

@code text file=linker.ld title="linker.ld: where each part of the kernel goes"
ENTRY(_start)
SECTIONS
{
    . = 1M;                                  /* the kernel is loaded at 1 MiB */
    .text   : { *(.multiboot) *(.text) *(.ashtext) }
    .rodata : { *(.rodata) }
    .data   : { *(.data) }
    .bss    : { *(.bss) }
}
@end

The ASH part of every kernel is a function `kmain(magic, info)` marked `@Entry`, compiled with `@bits(32)` and `--no-libc`. The build always has the same steps:

@code sh
shasm --lang en -f elf32 -o boot.o boot.asm      # assemble the entry point
ashc kernel.ash --elf --no-libc -s -o kernel.o    # compile the ASH code
ld -m elf_i386 -T linker.ld -o kernel.elf boot.o kernel.o
qemu-system-i386 -kernel kernel.elf               # boot it
@end

@section{bm-hello} Hello, Screen
The smallest useful kernel writes one line into video memory. It does not clear the screen, so the messages of the BIOS remain visible above it.

@code ash file=hello.ash title="hello.ash: writing characters into video memory"
@bits(32)

@Entry
pub func kmain(uint32 magic, uint32 info): void {
    uint8* video = 0xB8000;                  // the first cell of the screen
    string message = " Hello from an ASH kernel! ";
    int32 row = 9;                           // below the BIOS messages
    int32 i = 0;
    while (message[i] != 0) {
        int32 cell = (row * 80 + i) * 2;
        video[cell] = message[i];            // the character
        video[cell + 1] = 0x1F;              // white on blue
        i++;
    }
}
@end

@table widths=42,58 title="Line by line: hello.ash"
Code | What it does
`@bits(32)` | The kernel runs in 32-bit protected mode.
`pub func kmain(uint32 magic, uint32 info)` | Called by `boot.asm` with the two values that the loader leaves in `eax` and `ebx`.
`uint8* video = 0xB8000;` | A pointer to the first byte of text memory.
`int32 cell = (row * 80 + i) * 2;` | The byte offset of column `i` of row `row`.
`video[cell] = message[i];` | Stores the character code.
`video[cell + 1] = 0x1F;` | Stores its attribute: white (15) on blue (1).
(end of `kmain`) | Returns to `boot.asm`, which halts the processor with `cli` and `hlt`.
@end

@qemu run="qemu-system-i386 -kernel hello.elf -m 32M" wait=3 title="hello.ash running in QEMU" label=fig-bm-hello
$ shasm --lang en -f elf32 -o boot.o boot.asm
$ ashc hello.ash --elf --no-libc -s -o hello.o
$ ld -m elf_i386 -z noexecstack --no-warn-rwx-segments -T linker.ld -o hello.elf boot.o hello.o
@end

@section{bm-colors} All the Colors
The next kernel shows every color the text screen offers. Below the BIOS messages ("Booting from ROM...") it draws sixteen squares of space characters, each with a different background, and a row of block characters in each foreground color.

@code ash file=colors.ash title="colors.ash: squares in the sixteen VGA colors"
@bits(32)

define VGA 0xB8000;

func put_at(int32 col, int32 row, int32 ch, int32 attr): void {
    uint8* cell = VGA + (row * 80 + col) * 2;
    cell[0] = ch;
    cell[1] = attr;
}

func text_at(int32 col, int32 row, string s, int32 attr): void {
    int32 i = 0;
    while (s[i] != 0) {
        put_at(col + i, row, s[i], attr);
        i++;
    }
}

// a block of 8 x 3 cells whose background is the given color
func square(int32 col, int32 row, int32 color): void {
    for (int32 y = 0; y < 3; y++) {
        for (int32 x = 0; x < 8; x++) {
            put_at(col + x, row + y, ' ', color << 4);
        }
    }
}

@Entry
pub func kmain(uint32 magic, uint32 info): void {
    text_at(0, 8, " The 16 VGA colors, drawn by an ASH kernel at 0xB8000 ", 0x1E);
    for (int32 c = 0; c < 16; c++) {
        int32 col = (c % 8) * 10;
        int32 row = 10 + (c / 8) * 5;
        square(col, row, c);
        put_at(col, row + 3, '0' + c / 10, 0x0F);
        put_at(col + 1, row + 3, '0' + c % 10, 0x0F);
    }
    for (int32 c = 1; c < 16; c++) {
        put_at(c * 4, 21, 0xDB, c);              // a full block in color c
        put_at(c * 4 + 1, 21, 0xDB, c);
        put_at(c * 4 + 2, 21, 'A' + c - 1, c);   // a letter in color c
    }
    text_at(0, 23, "Attribute byte = background * 16 + foreground", 0x07);
}
@end

@qemu run="qemu-system-i386 -kernel colors.elf -m 32M" wait=3 title="colors.ash: the sixteen colors below the BIOS messages" label=fig-bm-colors
$ shasm --lang en -f elf32 -o boot.o boot.asm
$ ashc colors.ash --elf --no-libc -s -o colors.o
$ ld -m elf_i386 -z noexecstack --no-warn-rwx-segments -T linker.ld -o colors.elf boot.o colors.o
@end

Square 0 is black on black, so it is invisible; squares 8 to 15 are the bright colors, which QEMU's VGA shows as backgrounds because blinking is disabled.

@section{bm-driver} A Small VGA Driver
Writing cells one by one quickly becomes tedious. The file `vga.ash` collects the operations every kernel needs: clearing the screen, writing text that wraps and scrolls, printing numbers in decimal and hexadecimal, drawing frames and bars, and moving the blinking hardware cursor. The cursor is not in video memory: it is a register of the video card's CRT controller, reached through the I/O ports `0x3D4` (register index) and `0x3D5` (value) with the `out` instruction.

@code ash file=vga.ash title="vga.ash: a reusable text-mode driver"
// vga.ash - a small driver for the VGA text screen (80 x 25 cells at 0xB8000)
define VGA_TEXT 0xB8000;
define VGA_COLS 80;
define VGA_ROWS 25;

general static int32 vga_row = 0
general static int32 vga_col = 0
general static int32 vga_color = 0x07

// attribute byte: background color in bits 4-6, foreground color in bits 0-3
func vga_attr(int32 fg, int32 bg): int32 {
    return (bg << 4) | fg;
}

func vga_put(int32 col, int32 row, int32 ch, int32 attr): void {
    uint8* cell = VGA_TEXT + (row * VGA_COLS + col) * 2;
    cell[0] = ch;
    cell[1] = attr;
}

func vga_clear(int32 attr): void {
    for (int32 i = 0; i < VGA_COLS * VGA_ROWS; i++) {
        vga_put(i % VGA_COLS, i / VGA_COLS, ' ', attr);
    }
    vga_row = 0;
    vga_col = 0;
}

func vga_goto(int32 col, int32 row): void {
    vga_col = col;
    vga_row = row;
}

// move the blinking hardware cursor: CRT controller registers 14 and 15
func vga_cursor(int32 col, int32 row): void {
    int32 pos = row * VGA_COLS + col;
    int32 high = (pos >> 8) & 255;
    int32 low = pos & 255;
    asm {
        mov dx, 0x3D4
        mov al, 14
        out dx, al
        mov dx, 0x3D5
        mov eax, high
        out dx, al
        mov dx, 0x3D4
        mov al, 15
        out dx, al
        mov dx, 0x3D5
        mov eax, low
        out dx, al
    }
}

// move every line up by one and clear the last line
func vga_scroll(): void {
    uint8* screen = VGA_TEXT;
    for (int32 i = 0; i < (VGA_ROWS - 1) * VGA_COLS * 2; i++) {
        screen[i] = screen[i + VGA_COLS * 2];
    }
    for (int32 c = 0; c < VGA_COLS; c++) {
        vga_put(c, VGA_ROWS - 1, ' ', vga_color);
    }
    vga_row = VGA_ROWS - 1;
}

func vga_putc(int32 ch): void {
    if (ch == '\n') {
        vga_col = 0;
        vga_row = vga_row + 1;
    } else {
        vga_put(vga_col, vga_row, ch, vga_color);
        vga_col = vga_col + 1;
        if (vga_col == VGA_COLS) {
            vga_col = 0;
            vga_row = vga_row + 1;
        }
    }
    if (vga_row == VGA_ROWS) {
        vga_scroll();
    }
}

func vga_puts(uint8* s): void {
    int32 i = 0;
    while (s[i] != 0) {
        vga_putc(s[i]);
        i++;
    }
}

func vga_dec(uint32 v): void {
    uint8[12] digits;
    int32 n = 0;
    if (v == 0) {
        vga_putc('0');
        return;
    }
    while (v > 0) {
        digits[n] = '0' + v % 10;
        v = v / 10;
        n++;
    }
    while (n > 0) {
        n--;
        vga_putc(digits[n]);
    }
}

func vga_hex(uint32 v): void {
    vga_puts("0x");
    for (int32 shift = 28; shift >= 0; shift = shift - 4) {
        int32 d = (v >> shift) & 15;
        if (d < 10) { vga_putc('0' + d); } else { vga_putc('A' + d - 10); }
    }
}

// a frame drawn with the double-line characters of code page 437
func vga_frame(int32 col, int32 row, int32 w, int32 h, int32 attr): void {
    vga_put(col, row, 0xC9, attr);
    vga_put(col + w - 1, row, 0xBB, attr);
    vga_put(col, row + h - 1, 0xC8, attr);
    vga_put(col + w - 1, row + h - 1, 0xBC, attr);
    for (int32 x = 1; x < w - 1; x++) {
        vga_put(col + x, row, 0xCD, attr);
        vga_put(col + x, row + h - 1, 0xCD, attr);
    }
    for (int32 y = 1; y < h - 1; y++) {
        vga_put(col, row + y, 0xBA, attr);
        vga_put(col + w - 1, row + y, 0xBA, attr);
    }
}

// a bar of 'full' cells out of 'size', in the given color
func vga_bar(int32 col, int32 row, int32 size, int32 full, int32 attr): void {
    for (int32 i = 0; i < size; i++) {
        if (i < full) {
            vga_put(col + i, row, 0xDB, attr);
        } else {
            vga_put(col + i, row, 0xB0, 0x08);
        }
    }
}
@end

@table widths=30,70 title="Functions of vga.ash" label=tab-vga-api
Function | What it does
`vga_attr(fg, bg)` | Builds an attribute byte from two colors of [[tab-vga-colors]].
`vga_put(col, row, ch, attr)` | Writes one character with one attribute at a position.
`vga_clear(attr)` | Fills the screen with spaces of the given attribute and moves the text position to the top left.
`vga_goto(col, row)` | Sets the position where the next text goes.
`vga_putc(ch)` | Writes one character at the text position in `vga_color`; handles `\n`, line wrapping and scrolling.
`vga_puts(s)` | Writes a string with `vga_putc`.
`vga_dec(v)`, `vga_hex(v)` | Write a number in decimal, or as `0x` followed by eight hexadecimal digits.
`vga_frame(col, row, w, h, attr)` | Draws a double-line frame with the characters `0xC9`, `0xBB`, `0xC8`, `0xBC`, `0xCD`, `0xBA`.
`vga_bar(col, row, size, full, attr)` | Draws a bar of `size` cells, the first `full` of them solid (`0xDB`), the rest shaded (`0xB0`).
`vga_cursor(col, row)` | Moves the hardware cursor: writes the high and low byte of `row * 80 + col` to CRT registers 14 and 15.
`vga_scroll()` | Moves every line up by one and clears the last line.
@end

The following kernel uses the driver to draw a control panel:

@code ash file=dash.ash title="dash.ash: a control panel drawn with vga.ash"
@bits(32)
import "vga.ash";

@Entry
pub func kmain(uint32 magic, uint32 info): void {
    vga_clear(vga_attr(7, 0));
    vga_frame(0, 0, 80, 25, vga_attr(11, 0));
    vga_goto(2, 1);
    vga_color = vga_attr(14, 0);
    vga_puts("ASH KERNEL CONTROL PANEL");
    vga_frame(2, 3, 36, 10, vga_attr(10, 0));
    vga_frame(41, 3, 37, 10, vga_attr(13, 0));
    string[] names = {"CPU", "Memory", "Disk", "Network", "Video"};
    int32[] levels = {18, 11, 6, 14, 20};
    int32[] colors = {12, 14, 10, 9, 13};
    for (int32 i = 0; i < 5; i++) {
        vga_goto(4, 5 + i);
        vga_color = vga_attr(15, 0);
        vga_puts(names[i]);
        vga_bar(13, 5 + i, 22, levels[i], vga_attr(colors[i], 0));
    }
    vga_goto(43, 5);
    vga_color = vga_attr(7, 0);
    vga_puts("Numbers, written by vga_dec/hex:");
    int32 v = 1;
    for (int32 r = 0; r < 5; r++) {
        vga_goto(45, 6 + r);
        vga_dec(v);
        vga_goto(57, 6 + r);
        vga_hex(v);
        v = v * 37;
    }
    vga_goto(2, 14);
    vga_color = vga_attr(15, 1);
    vga_puts(" Every character on this screen is two bytes in memory at 0xB8000. ");
    vga_goto(2, 16);
    for (int32 c = 0; c < 16; c++) {
        vga_color = vga_attr(c, 0);
        vga_putc(0xDB);
        vga_putc(0xDB);
        vga_color = vga_attr(15, c);
        vga_putc('A' + c);
        vga_putc(' ');
    }
    vga_goto(2, 22);
    vga_color = vga_attr(10, 0);
    vga_puts("> ready_");
    vga_cursor(10, 22);
}
@end
